⚙️ C Language Engine & Architecture

Core Engine Architecture (For Teacher & Viva):

  • Language: Standard C (C99), stored in c_src/ludo.c & c_src/ludo.h.
  • Data Structures:
    • struct Player: Tracks 4 tokens per player using relative steps (-1 to 56) and home counts.
    • struct GameState: Holds complete game snapshots, active turn, dice rolls, safe spots, and win state.
  • Core Mechanics in C:
    • roll_dice(): Generates random rolls 1 to 6 using (rand() % 6) + 1.
    • can_move_token(): Custom rule allows tokens in base (-1) to unlock on ANY roll (1-6).
    • move_token(): Moves token, verifies 8 safe spots (stars), captures opponent tokens on non-safe tiles, and awards extra turns on 6.
    • get_common_tile(): Maps relative step (0-50) to the circular 52-tile track using (start_tile + step) % 52.
  • GitHub Pages Deployment: Hosted 100% statically on GitHub Pages with WebRTC (PeerJS) for serverless, peer-to-peer real-time multiplayer!
