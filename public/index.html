⚙️ C Language Architecture & Viva Guide

Sir/Teacher Explanation Summary:

  • Language: Standard C (C99), compiled with gcc -O2 ludo.c -o ludo_engine.
  • Data Structures:
    • struct Player: Tracks 4 tokens (step -1 to 56) and home count.
    • struct GameState: Encapsulates turn, dice, safe spots, and win state.
  • Core Mechanics in C:
    • roll_dice(): Generates random dice rolls 1 to 6.
    • can_move_token(): Validates if token can exit base or advance.
    • move_token(): Performs token movement, captures opponents on non-safe tiles, checks home arrival, and grants bonus turn on 6.
    • get_common_tile(): Maps relative step to global 52-tile ring using (start_tile + step) % 52.
  • Web & Cloud Bridge: Node.js server executes the compiled C binary via child_process.execFile and syncs multiplayer state across Socket.io clients.
